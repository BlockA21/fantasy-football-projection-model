# 2025 Fantasy Football PPR Projection Model

A Python model that projects 2025 NFL fantasy football rankings across 
QB, RB, WR, and TE using 5 seasons of weekly player data.

## How It Works
- Recency-weighted scoring (70/20/10 across last 3 seasons)
- Position-specific age decay
- Injury/absence penalties
- Late-season momentum boost
- Career-elite tier bonus (top 20% per position)

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn

## Data
Weekly offensive player stats (2020–2024). Data not included in repo.
